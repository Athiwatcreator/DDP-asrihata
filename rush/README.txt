PIXEL PLANET — DISCOVERY PISCINE RUSH

Files:
- index.html: page structure and content
- style.css: colors, layout, responsive design, and dark theme styles
- script.js: theme button, mobile navigation, and quest form
- pixel-world.svg: local illustration used by the page
- auteur: replace the two placeholder lines with both teammates' actual 42 logins

HOW TO RUN:
1. Open this folder in Visual Studio Code.
2. Open index.html.
3. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Otherwise, open index.html directly in Firefox or Chrome.

- Keep all these files together inside ~/discovery-piscine/rush.
